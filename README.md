# No Pause Challenge

No Pause Challenge removes the safety of stopping time.

The pause button is gone, dialogs no longer freeze the game, and you must play in real time. You still get speed controls, including faster speeds, but you do not get to stop and think forever.

The challenge can be enabled per game from the storyteller dialog, even on existing saves. If you want RimWorld to feel more urgent, this is the pressure switch.
